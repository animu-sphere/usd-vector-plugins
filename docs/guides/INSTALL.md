# Installation

Status: the GeoJSON plugin has an installable bundle layout generated by the
OpenStrata `usd-fileformat-cpp` template.

## Bundle layout

```text
<prefix>/
  lib/                         plugin shared library
  plugin/resources/vector-geojson/
    plugInfo.json              USD registration metadata
  openstrata.plugin.yaml       bundle contract
  openstrata.scaffold.yaml     template provenance
  tests/fixtures/              smoke, negative, and golden fixtures
```

The installed `plugInfo.json` uses paths relative to its bundle. Installation
must not embed a build-directory path.

## CMake installation

For a configured full build:

```powershell
cmake --install build/full --prefix C:\usd-vector-plugins
```

Add the installed plugin registration directory to `PXR_PLUGINPATH_NAME`:

```powershell
$env:PXR_PLUGINPATH_NAME = "C:\usd-vector-plugins\plugin\resources\vector-geojson;$env:PXR_PLUGINPATH_NAME"
```

Use `ost plugin inspect`, `ost plugin doctor`, or the integration checks to
confirm that `UsdVectorGeoJsonFileFormat` is discovered before attempting to
open a source.
Do not copy only the shared library; registration metadata and relative
resources are part of the artifact.

## Compatibility

The plugin must be built against an ABI-compatible OpenUSD runtime and C++
toolchain. This bundle targets OpenUSD `>=26.08,<27.0`, platform `cy2026`, and
profile `usd`. Release artifacts are target-qualified rather than advertised
as universally portable. Resolver implementations are installed separately
and compose at runtime through OpenUSD.
