# v0.1.0

Released 2026-09-04.

## Scope

The first release provides a read-only GeoJSON vertical slice from source
bytes through a deterministic OpenUSD FileFormat plugin. Transport and
reprojection remain host or resolver responsibilities.

## Supported behavior

- `.geojson` FeatureCollection sources and GeoJSON-bearing `.json` sources.
- Point, MultiPoint, LineString, MultiLineString, Polygon, MultiPolygon, and
  null geometry features.
- Polygon holes, typed scalar properties, homogeneous scalar arrays, nested
  value fallback, feature and dataset bounds, foreign members, and legacy CRS
  preservation.
- Local file, in-memory, and resolver-provided `ArAsset` sources.
- Strict and non-strict diagnostics for malformed sources and duplicate IDs.

## Authored USD

The plugin authors the documented `/Vector` hierarchy with deterministic
feature names and prim paths. Polygon geometry is triangulated, coordinates
are processed internally as doubles, and a deterministic bounds-center local
origin plus source-coordinate metadata preserve precision and recoverability.

## File-format arguments

The supported arguments are `strict=true|false`, `properties=all|none`, and
`geometry=all|points|curves|meshes|none`.

## Known limitations

- The default reader is buffered. A tested lazy reader candidate exists, but
  it is not the v0.1 default or a fully bounded-memory parser.
- No implicit reprojection, axis conversion, spatial index, tiling, payload
  generation, or resumable conversion is included.
- Bare Geometry roots and GeometryCollection are deferred.
- Invalid self-intersecting polygons are rejected rather than repaired.

## Build requirements

OpenUSD 26.08 with compatibility range `>=26.08,<27.0`, the `cy2026` / `usd`
OpenStrata profile, CMake 3.24 or newer, Ninja or another CMake generator,
and a C++17 compiler compatible with the runtime ABI. The OpenUSD-free core
lane does not require OpenUSD.

## Dependencies and licensing

Project code is Apache-2.0. OpenUSD and nlohmann/json are documented runtime
or build dependencies. `LICENSE`, `NOTICE`, and
`THIRD_PARTY_NOTICES.md` define the distribution terms.

## Verification

The release evidence covers core and authoring tests, GeoJSON reader tests,
plugin discovery, resolver-backed reads, `.json` probing, malformed-input
diagnostics, deterministic output, USDA serialization, flatten/reopen, and
the OpenStrata L0-L5 plugin verification pyramid. The corresponding local
OpenStrata report is
[01-2026-09-02-v0.22.8-geojson-fileformat-dogfooding.md](../reports/ost/01-2026-09-02-v0.22.8-geojson-fileformat-dogfooding.md).

The target-qualified OpenStrata package and aggregate product were generated
twice with identical package and product digests. A clean CMake install was
also verified to contain the plugin resources, fixtures, manifests, and the
repository `LICENSE`, `NOTICE`, and `THIRD_PARTY_NOTICES.md` under
`share/usd-vector-plugins/`.
