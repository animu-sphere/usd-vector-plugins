# v0.2.0

Released 2026-09-12.

## Scope

This release makes the GeoJSON product suitable for composition with the
OpenStrata-managed `cy2026` / `usd` runtime. The release workflow builds,
tests, packages, and publishes the product from the same pinned runtime
materialization, then records the immutable OCI reference for consumers.

## Supported behavior

- `.geojson` FeatureCollection sources and GeoJSON-bearing `.json` sources.
- Point, MultiPoint, LineString, MultiLineString, Polygon, MultiPolygon, and
  null geometry features.
- Polygon holes, typed scalar properties, homogeneous scalar arrays, nested
  value fallback, feature and dataset bounds, foreign members, and legacy CRS
  preservation.
- Local file, in-memory, and resolver-provided `ArAsset` sources.
- Strict and non-strict diagnostics for malformed sources and duplicate IDs.
- Direct-read stage arguments for `upAxis` and `metersPerUnit`, with `/Vector`
  authored as the default prim when the source is opened directly.

## Authored USD

The plugin authors the documented `/Vector` hierarchy with deterministic
feature names and prim paths. Polygon geometry is triangulated, coordinates
are processed internally as doubles, and a deterministic bounds-center local
origin plus source-coordinate metadata preserve precision and recoverability.

## Release integrity

The product manifest is checked against `strata.lock` before publication. The
runtime provenance digest must match the lock and unmanaged local runtimes are
rejected. The package is imported and pushed by the tag-triggered workflow,
which also requires and verifies its embedded SBOM and in-toto provenance.
The workflow generates GitHub provenance and SBOM attestations without adding
attestation layers to the GHCR image, because the OpenStrata product already
carries the evidence consumed by downstream composition.

The installed acceptance probe remains at
`share/usd-vector-plugins/probes/packaged_probe.py`, accepts only
`--prefix <composed prefix>`, resolves its fixtures from the installed product,
and reports both refusal checks and a positive authored `featureCount`.

## Known limitations

- The default reader is buffered. The tested lazy reader candidate is not yet a
  fully bounded-memory parser for every source shape.
- No implicit reprojection, axis conversion, spatial index, tiling, payload
generation, or resumable conversion is included.
- Bare Geometry roots and GeometryCollection are deferred.
- Invalid self-intersecting polygons are rejected rather than repaired.

## Build requirements

OpenUSD 26.08 with compatibility range `>=26.08,<27.0`, the `cy2026` / `usd`
OpenStrata profile, CMake 3.24 or newer, Ninja or another CMake generator,
and a C++17 compiler compatible with the runtime ABI. The OpenUSD-free core
lane does not require OpenUSD.

## Verification

The release gate covers release metadata, the OpenUSD-free CMake lane, the
OpenStrata runtime and plugin verification pyramid, the packaged acceptance
probe, SBOM validation, and runtime provenance matching against `strata.lock`.
The final product is published under
`oci://ghcr.io/animu-sphere/usd-vector-plugins` and consumers pin the OCI
reference recorded by the release workflow.
